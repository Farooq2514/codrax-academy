# Codrax Academy website

## Run locally

Open this folder in VS Code and use Live Server to open `index.html`. Keep the
HTML, JavaScript, CSS and `images` folder together. The site does not need an
npm build.

## Main files

- `index.html` — homepage and interactive Java quiz
- `courses.html` — combined backend batch, package and course catalogue
- `course-data.js` — course fees, durations, topic lists and highlights
- `courses-page.js` — homepage and catalogue cards
- `course-page.js` — data-driven course details
- `course-hld.html`, `course-ai-agents.html` — added course detail pages
- `chatbot.js` — prepared course FAQ assistant
- `launch.js` — demo enquiry form submission
- `style.css` — shared responsive site styling
- `dashboard.html` — frontend dashboard demonstration; real accounts and
  access control require the Java backend
