# Codrax Academy — Complete Website

## Open on Windows
1. Extract this ZIP using Extract All.
2. Open the Codrax-Academy folder.
3. Double-click index.html. Keep all files together.
No npm install, build, API key, or paid chatbot service is needed.
Fonts load from Google Fonts while online; fallback fonts work offline.

## Publishing
Upload the extracted website files to the published folder of your existing hosting or GitHub Pages repository, with index.html at the top level. Back up your existing files first. Upload the files, not the ZIP. This package does not update your GitHub repository automatically.
