TRY AN ASSIGNMENT

Write it. Trace it. Explain it.

Add the numbers from 1 to 5

Use a Java loop to calculate the total. Predict the output before opening the solution.

View the explained solution 
int total = 0;

for (int i = 1; i <= 5; i++) {
    total += i;
}

System.out.println(total);

The total starts at 0. Each iteration adds the next number: 1, 2, 3, 4, then 5. The program prints 15. When i becomes 6, the condition is false and the loop ends.

A few useful answers.

What does the complete package include?

Includes Java Backend Development, DSA, Low-Level Design, and HTML & CSS. Git & GitHub is taught within the backend batch.

How do mentor sessions work?

Complimentary mentor credits are available with eligible learning paths. Ask us to confirm whether credits apply to your selected course and to discuss session length, booking, validity and missed-session rules. Weekend teaching assistant support is separate.

Do I need coding experience?

No coding experience is needed to begin the Java foundation or HTML & CSS. DSA assumes basic programming confidence, and LLD assumes object-oriented programming knowledge. You need a laptop or desktop, internet access and time to practice.

Is Git & GitHub a separate purchase?

You can study it separately if you only need version control. It is already included in the Java backend batch and the complete package, so those learners do not need to buy it again.

Do you teach AI and AI agents?

Yes. The separate 21-day AI & Agents course covers the LLM landscape, prompt engineering, built-in tools, RAG, agents, n8n and Zapier, OpenClaw, multi-agent systems and debugging with vibecoding tools.

In the Java backend course, learners practise using GPT as an assistant and reviewing, testing and explaining generated code.

How are classes, support and recordings arranged?

Before joining, request the batch timetable in IST, total sessions, session length, weekly practice expectations, and individual or group support arrangements. Recording availability, access duration, and any certificate requirements must also be confirmed for your course.

What happens after I request a demo?
